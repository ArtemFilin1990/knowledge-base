# Обозначения NSK

Система обозначений подшипников японского производителя NSK.

## Контекст применения

- Расшифровка каталожных номеров NSK
- Подбор аналогов NSK ↔ SKF ↔ ГОСТ
- Заказ подшипников

## Ключевые пункты

### Структура обозначения

```
[Базовое обозначение][Суффиксы]
```

Пример: **6205DDU** или **22210EAE4**

### Суффиксы уплотнений

| Суффикс | Описание |
|---------|----------|
| ZZ | Две металлические защитные шайбы |
| DDU | Два контактных резиновых уплотнения |
| DU | Одно резиновое уплотнение |
| Z | Одна защитная шайба |
| VV | Два бесконтактных уплотнения |

### Суффиксы зазоров

| Суффикс | Зазор |
|---------|-------|
| C2 | Уменьшенный |
| CM | Нормальный |
| C3 | Увеличенный |
| C4 | Значительно увеличенный |

### Суффиксы сепараторов

| Суффикс | Материал |
|---------|----------|
| M | Латунный |
| T | Пластиковый (полиамид) |
| J | Стальной |

### Серии подшипников

| Серия | Тип |
|-------|-----|
| 60.. | Глубокий желоб, лёгкая |
| 62.. | Глубокий желоб, лёгкая |
| 63.. | Глубокий желоб, средняя |
| 72.. | Радиально-упорные |
| HR 30.. | Конические |
| 222.. | Сферические роликовые |
| NU, NJ | Цилиндрические роликовые |

### Специальные обозначения

| Код | Значение |
|-----|----------|
| HR | High reliability (повышенная надёжность) |
| TAM | Высокоточные для станков |
| Robust | Усиленная конструкция |

## Примеры расшифровки

### 6205DDU

- **6** — глубокий желоб
- **2** — лёгкая серия
- **05** — d = 25 мм
- **DDU** — два резиновых уплотнения

### 22210EAE4

- **222** — сферический роликовый
- **10** — d = 50 мм
- **EA** — улучшенная конструкция
- **E4** — полиамидный сепаратор

### HR 30205 J

- **HR** — повышенная надёжность
- **302** — конический роликовый
- **05** — d = 25 мм
- **J** — стальной сепаратор

## Соответствие NSK → SKF

| NSK | SKF | Примечание |
|-----|-----|------------|
| DDU | -2RS1 | Уплотнения |
| ZZ | -2Z | Защитные шайбы |
| C3 | /C3 | Зазор |
| VV | -2RZ | Низкофрикционные |
