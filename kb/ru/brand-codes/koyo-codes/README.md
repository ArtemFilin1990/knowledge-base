# Обозначения KOYO

Система обозначений подшипников японского производителя KOYO (JTEKT).

## Контекст применения

- Расшифровка каталожных номеров KOYO
- Подбор аналогов

## Ключевые пункты

### Суффиксы уплотнений

| Суффикс | Описание |
|---------|----------|
| ZZ | Две металлические защитные шайбы |
| 2RS | Два резиновых уплотнения |
| 2RU | Два бесконтактных уплотнения |

### Суффиксы зазоров

| Суффикс | Зазор |
|---------|-------|
| C2 | Уменьшенный |
| (без) | Нормальный |
| C3 | Увеличенный |

### Суффиксы сепараторов

| Суффикс | Материал |
|---------|----------|
| M | Латунный |
| T | Пластиковый |

## Примеры

- **6205 2RS C3** — шариковый, d=25, два уплотнения, зазор C3
- **30205 JR** — конический роликовый, d=25
