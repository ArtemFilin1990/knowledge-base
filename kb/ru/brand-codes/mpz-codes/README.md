# Обозначения МПЗ

Система обозначений Минского подшипникового завода (МПЗ).

## Контекст применения

- Расшифровка обозначений белорусских подшипников
- Подбор импортных аналогов
- Заказ отечественных подшипников

## Ключевые пункты

### Общая информация

МПЗ использует **систему обозначений по ГОСТ 3189-89** с дополнительными заводскими суффиксами.

### Структура обозначения

```
[Класс точности]-[Основное обозначение][Суффиксы]
```

Пример: **6-180306С17Ш** или **6205-2RS**

### Заводские суффиксы МПЗ

| Суффикс | Значение |
|---------|----------|
| Ш | Малошумное исполнение |
| С17 | Смазка ЦИАТИМ-201 |
| С9 | Смазка ОКБ-122-7 |
| С2 | Смазка Литол-24 |
| Е | Сепаратор текстолитовый |
| Л | Латунный сепаратор |
| К | Коническое отверстие |

### Суффиксы уплотнений (ГОСТ)

| Суффикс | Описание |
|---------|----------|
| без | Открытый |
| 60 | Защитная шайба с одной стороны |
| 80 | Уплотнение резиновое с одной стороны |
| 2 | Защитные шайбы с двух сторон |
| 6 | Резиновые уплотнения с двух сторон |

### Классы точности

| Обозначение | Класс |
|-------------|-------|
| без | 0 (нормальный) |
| 6- | 6 |
| 5- | 5 |
| 4- | 4 |

## Примеры расшифровки

### 6-180306С17Ш

- **6-** — класс точности 6
- **1** — серия ширин
- **8** — упорный шариковый
- **03** — серия диаметров 0, ширин 3
- **06** — d = 30 мм
- **С17** — смазка ЦИАТИМ-201
- **Ш** — малошумное исполнение

### 6205-2RS

- **6205** — шариковый, лёгкая серия, d=25
- **-2RS** — два резиновых уплотнения

## Ассортимент МПЗ

МПЗ специализируется на:
- Шариковых радиальных
- Шариковых радиально-упорных
- Роликовых конических
- Игольчатых
- Упорных

## Соответствие МПЗ → SKF

| МПЗ (ГОСТ) | SKF | Примечание |
|------------|-----|------------|
| 6205 | 6205 | Идентично |
| 180205 | 61805 | Тонкостенный |
| 60205 | 6205-Z | Одна шайба |
| 80205 | 6205-RS | Одно уплотнение |
