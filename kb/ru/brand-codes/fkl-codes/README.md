# Обозначения FKL

Система обозначений подшипников сербского производителя FKL.

## Контекст применения

- Расшифровка каталожных номеров FKL
- Подбор аналогов

## Ключевые пункты

### О производителе

FKL (Temerin, Сербия) — европейский производитель качественных подшипников по конкурентным ценам.

### Система обозначений

FKL использует **систему, совместимую с ISO/DIN**, близкую к SKF.

### Суффиксы уплотнений

| Суффикс | Описание |
|---------|----------|
| 2RS | Два резиновых уплотнения |
| 2Z | Две защитные шайбы |
| RS | Одно уплотнение |

### Суффиксы зазоров

| Суффикс | Зазор |
|---------|-------|
| C2 | Уменьшенный |
| C3 | Увеличенный |

### Ассортимент

- Шариковые радиальные
- Сферические роликовые
- Конические роликовые
- Корпусные узлы

## Примеры

- **6205 2RS C3** — шариковый, d=25, уплотнения, зазор C3
- **22210 EK** — сферический роликовый, коническое отверстие
