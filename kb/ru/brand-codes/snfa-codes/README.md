# Обозначения SNFA

Система обозначений прецизионных подшипников SNFA (Франция).

## Контекст применения

- Подбор шпиндельных подшипников
- Расшифровка обозначений SNFA

## Ключевые пункты

### Специализация

SNFA специализируется на **шпиндельных и прецизионных** подшипниках для станков.

### Серии

| Серия | Тип |
|-------|-----|
| VEX | Радиально-упорные шариковые |
| SEA | Стандартные радиально-упорные |
| SEB | Усиленные |

### Суффиксы

| Суффикс | Значение |
|---------|----------|
| /NS | Нормальный преднатяг |
| /LS | Лёгкий преднатяг |
| /HS | Тяжёлый преднатяг |
| 7CE3 | Класс точности |

## Примеры

- **VEX 25 /NS 7CE3** — шпиндельный, d=25, нормальный преднатяг, высокая точность
