# Обозначения GMN

Система обозначений прецизионных подшипников GMN (Германия).

## Контекст применения

- Подбор шпиндельных подшипников GMN
- Расшифровка обозначений

## Ключевые пункты

### Специализация

GMN — немецкий производитель **высокоскоростных шпиндельных** подшипников.

### Серии

| Серия | Описание |
|-------|----------|
| S | Стандартные радиально-упорные |
| HS | Высокоскоростные |
| HY | Гибридные (керамика) |

### Суффиксы

| Суффикс | Значение |
|---------|----------|
| UL | Сверхлёгкий преднатяг |
| L | Лёгкий преднатяг |
| M | Средний преднатяг |
| EL | Сверхлёгкий |

## Примеры

- **S 6205 C TA P4 UL** — d=25, высокая точность, сверхлёгкий преднатяг
