# Обозначения FAG

Система обозначений подшипников немецкого производителя FAG (Schaeffler Group).

## Контекст применения

- Расшифровка каталожных номеров FAG
- Подбор аналогов FAG ↔ SKF ↔ ГОСТ
- Заказ подшипников

## Ключевые пункты

### Структура обозначения

```
[Базовое обозначение].[Суффиксы]
```

Пример: **6205.2RSR.C3** или **22210-E1-K**

### Суффиксы уплотнений

| Суффикс | Описание |
|---------|----------|
| .2ZR | Две металлические защитные шайбы |
| .2RSR | Два контактных резиновых уплотнения |
| .RSR | Одно резиновое уплотнение |
| .ZR | Одна защитная шайба |

### Суффиксы зазоров

| Суффикс | Зазор |
|---------|-------|
| .C2 | Уменьшенный |
| (без) | Нормальный CN |
| .C3 | Увеличенный |
| .C4 | Значительно увеличенный |

### Суффиксы сепараторов

| Суффикс | Материал |
|---------|----------|
| .M | Латунный массивный |
| .TVP, .TVH | Полиамид |
| .J | Стальной штампованный |

### Суффиксы для сферических роликовых

| Суффикс | Значение |
|---------|----------|
| -E1 | Улучшенная конструкция |
| -K | Коническое отверстие |
| -XL | Увеличенная грузоподъёмность |

### Конические роликовые

| Серия | Описание |
|-------|----------|
| 302.. | Однорядные |
| 313.. | Однорядные широкие |
| 320.. | Однорядные |
| 331.. | Парные |

## Примеры расшифровки

### 6205.2RSR.C3

- **6205** — шариковый радиальный, лёгкая серия, d=25
- **.2RSR** — два резиновых уплотнения
- **.C3** — зазор C3

### 22210-E1-K

- **222** — сферический роликовый двухрядный
- **10** — d = 50 мм
- **-E1** — улучшенная конструкция
- **-K** — коническое отверстие 1:12

### NU 206-E-XL-TVP2

- **NU** — роликовый цилиндрический
- **206** — лёгкая серия, d=30
- **-E** — усиленная конструкция
- **-XL** — увеличенная грузоподъёмность
- **-TVP2** — полиамидный сепаратор

## Соответствие FAG → SKF

| FAG | SKF | Примечание |
|-----|-----|------------|
| .2RSR | -2RS1 | Уплотнения |
| .2ZR | -2Z | Защитные шайбы |
| .C3 | /C3 | Зазор |
| .M | M | Латунный сепаратор |
