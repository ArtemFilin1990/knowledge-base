# Обозначения NTN-SNR

Система обозначений подшипников NTN (Япония) и SNR (Франция).

## Контекст применения

- Расшифровка каталожных номеров NTN и SNR
- Подбор аналогов
- Заказ подшипников

## Ключевые пункты

### О бренде

NTN Corporation (Япония) и SNR Roulements (Франция) объединились в группу NTN-SNR. Оба бренда сохраняют свои системы обозначений.

### Обозначения NTN

#### Суффиксы уплотнений NTN

| Суффикс | Описание |
|---------|----------|
| ZZ | Две металлические защитные шайбы |
| LLU | Два контактных резиновых уплотнения |
| LLB | Два бесконтактных уплотнения |
| Z | Одна защитная шайба |

#### Суффиксы зазоров NTN

| Суффикс | Зазор |
|---------|-------|
| C2 | Уменьшенный |
| CM | Нормальный |
| C3 | Увеличенный |
| C4 | Значительно увеличенный |

### Обозначения SNR

#### Суффиксы уплотнений SNR

| Суффикс | Описание |
|---------|----------|
| .ZZ | Две защитные шайбы |
| .EE | Два резиновых уплотнения |
| .Z | Одна защитная шайба |
| .E | Одно уплотнение |

#### Суффиксы SNR

| Суффикс | Значение |
|---------|----------|
| .G2 | Зазор C3 |
| .G1 | Зазор C2 |
| .J30 | Латунный сепаратор |

## Примеры расшифровки

### NTN: 6205LLU/5K

- **6205** — шариковый, лёгкая серия, d=25
- **LLU** — два резиновых уплотнения
- **/5K** — специальная смазка

### SNR: 6205.EE.G2

- **6205** — шариковый, лёгкая серия, d=25
- **.EE** — два резиновых уплотнения
- **.G2** — зазор C3

## Соответствие NTN/SNR → SKF

| NTN | SNR | SKF |
|-----|-----|-----|
| LLU | .EE | -2RS1 |
| ZZ | .ZZ | -2Z |
| C3 | .G2 | /C3 |

## Специализация

- **NTN:** Автомобильные, промышленные, шарниры
- **SNR:** Автомобильные подшипники, ступичные узлы
