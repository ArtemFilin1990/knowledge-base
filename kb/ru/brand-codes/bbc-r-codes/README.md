# Обозначения BBC-R

Система обозначений подшипников производителя BBC-R.

## Контекст применения

- Расшифровка каталожных номеров BBC-R
- Подбор аналогов

## Ключевые пункты

### Система обозначений

BBC-R использует стандартную систему, совместимую с ISO.

### Суффиксы

| Суффикс | Описание |
|---------|----------|
| 2RS | Два резиновых уплотнения |
| 2Z | Две защитные шайбы |
| C3 | Зазор C3 |

### Ассортимент

- Шариковые радиальные
- Роликовые

## Примеры

- **6205 2RS** — шариковый, d=25, два уплотнения
