# Обозначения SKF

Система обозначений подшипников шведского производителя SKF.

## Контекст применения

- Расшифровка каталожных номеров SKF
- Подбор аналогов
- Заказ подшипников с нужными характеристиками

## Ключевые пункты

### Структура обозначения

```
[Префикс] [Базовое обозначение] [Суффиксы]
```

Пример: **W 61905-2RS1** или **6205-2RSH**

### Основные префиксы

| Префикс | Значение |
|---------|----------|
| W | Нержавеющая сталь |
| GE..ES | Сферический шарнирный |
| NU | Роликовый цилиндрический |
| NJ | Роликовый цилиндрический |
| NUP | Роликовый цилиндрический |
| 7.. | Радиально-упорный |
| 30.. | Конический роликовый |
| 22.. | Сферический роликовый |
| 23.. | Сферический роликовый |

### Суффиксы уплотнений

| Суффикс | Описание |
|---------|----------|
| -2Z | Две металлические защитные шайбы |
| -2RS1 | Два контактных резиновых уплотнения |
| -2RSH | Два резиновых уплотнения (новый дизайн) |
| -2RZ | Два низкофрикционных уплотнения |
| /C3 | Зазор C3 |
| /C2 | Зазор C2 |

### Суффиксы сепараторов

| Суффикс | Материал |
|---------|----------|
| M | Латунный массивный |
| TN9 | Полиамид (стеклонаполненный) |
| Y | Латунный штампованный |

### Суффиксы точности

| Суффикс | Класс ISO |
|---------|-----------|
| /P5 | P5 |
| /P4 | P4 |
| /P2 | P2 |
| /PA9A | Сверхвысокая точность |

### Специальные серии

| Обозначение | Характеристика |
|-------------|----------------|
| Explorer | Улучшенная конструкция (без отдельной маркировки с 2003) |
| E2 | Энергоэффективные |
| HN | Гибридные (керамика) |

## Примеры расшифровки

### 6205-2RSH

- **6** — глубокий желоб, однорядный
- **2** — лёгкая серия
- **05** — d = 25 мм
- **-2RSH** — два резиновых уплотнения

### W 61905-2RS1

- **W** — нержавеющая сталь
- **619** — сверхлёгкая серия
- **05** — d = 25 мм
- **-2RS1** — два резиновых уплотнения

### 22210 E/C3

- **22** — сферический роликовый
- **2** — лёгкая серия
- **10** — d = 50 мм
- **E** — усиленная конструкция
- **/C3** — зазор C3
