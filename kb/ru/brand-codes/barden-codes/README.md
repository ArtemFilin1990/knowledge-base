# Обозначения BARDEN

Система обозначений прецизионных подшипников BARDEN (Schaeffler Group).

## Контекст применения

- Подбор прецизионных подшипников
- Расшифровка обозначений BARDEN

## Ключевые пункты

### Специализация

BARDEN — американский бренд (теперь Schaeffler) для **сверхточных и шпиндельных** подшипников.

### Серии

| Серия | Тип |
|-------|-----|
| 100 | Радиально-упорные, угол 15° |
| 200 | Радиально-упорные, угол 25° |
| 300 | Радиально-упорные, угол 40° |

### Суффиксы

| Суффикс | Значение |
|---------|----------|
| H | Высокоскоростной |
| DL | Двойное уплотнение |
| T | Универсальная комплектация |

## Примеры

- **106 HDL** — радиально-упорный 15°, высокоскоростной, с уплотнениями
