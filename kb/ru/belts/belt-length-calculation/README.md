# Расчёт длины ремня

Формулы для расчёта длины приводного ремня по диаметрам шкивов и межосевому расстоянию.

## Контекст применения

- Проектирование ременной передачи
- Определение длины при замене
- Расчёт межосевого расстояния

## Ключевые пункты

### Основная формула

Для двухшкивной передачи:

```
L = 2a + π(D + d)/2 + (D - d)²/(4a)
```

где:
- L — расчётная длина ремня, мм
- a — межосевое расстояние, мм
- D — диаметр большого шкива, мм
- d — диаметр малого шкива, мм

### Упрощённая формула

При малой разнице диаметров (D ≈ d):

```
L ≈ 2a + 1.57(D + d)
```

### Обратная задача: межосевое расстояние

```
a = (L - π(D + d)/2 + √((L - π(D + d)/2)² - 2(D - d)²)) / 4
```

Или упрощённо:

```
a ≈ (L - 1.57(D + d)) / 2
```

### Пример расчёта

**Дано:**
- D = 200 мм
- d = 100 мм  
- a = 400 мм

**Расчёт:**
```
L = 2×400 + 3.14×(200+100)/2 + (200-100)²/(4×400)
L = 800 + 471 + 6.25
L = 1277 мм
```

Выбираем ближайший стандартный размер: **L = 1280 мм** или **1270 мм**

### Таблица стандартных длин (клиновые)

| Профиль | Диапазон Li, мм | Шаг, мм |
|---------|-----------------|---------|
| Z | 400–2500 | 25/50 |
| A | 530–4000 | 25/50 |
| B | 630–6300 | 50/100 |
| C | 1000–10000 | 100 |

### Для зубчатых ремней

```
Длина = Число зубьев × Шаг
```

или

```
Число зубьев = (2a + π(z₁ + z₂)/2) / P
```

где z₁, z₂ — числа зубьев шкивов, P — шаг

## Калькулятор

## Частые ошибки

- Путают внутреннюю и расчётную длину
- Не учитывают растяжение нового ремня
- Неточно измеряют межосевое расстояние
