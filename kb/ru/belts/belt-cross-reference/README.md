# Аналоги ремней ГОСТ — импорт

Таблица соответствия обозначений ремней по ГОСТ и импортным стандартам.

## Контекст применения

- Подбор импортного аналога для ремня по ГОСТ
- Подбор отечественного аналога для импортного ремня
- Унификация обозначений

## Ключевые пункты

### Клиновые ремни — профили

| ГОСТ (СНГ) | ISO/DIN | США | Сечение, мм |
|------------|---------|-----|-------------|
| О (SPO) | Z | — | 10 × 6 |
| А (SPA) | A | A | 13 × 8 |
| Б (SPB) | B | B | 17 × 11 |
| В (SPC) | C | C | 22 × 14 |
| Г | D | D | 32 × 19 |
| Д | E | E | 38 × 24 |

### Узкие клиновые — профили

| ГОСТ | ISO (SPZ, SPA, SPB, SPC) |
|------|--------------------------|
| УО | SPZ (9.7 × 8) |
| УА | SPA (12.7 × 10) |
| УБ | SPB (16.3 × 13) |
| УВ | SPC (22 × 18) |

### Пересчёт длины

#### ГОСТ → ISO (клиновые)

```
Lw (ISO) ≈ Li (ГОСТ) + Δ
```

| Профиль | Δ, мм |
|---------|-------|
| Z/О | +31 |
| A/А | +33 |
| B/Б | +43 |
| C/В | +56 |

### Примеры соответствия

| УА-1000 | SPA 1000 | Длина Lw |

## Частые ошибки

- Путают внутреннюю (Li) и расчётную (Lw) длину
- Подбирают профиль только по ширине, без учёта высоты
- Используют разные системы измерения длины
