# Подбор ремня по размеру

Инструкция по определению параметров и подбору приводного ремня.

## Контекст применения

- Замена изношенного ремня
- Подбор аналога
- Определение размера без маркировки

## Ключевые пункты

### Что нужно измерить

1. **Тип ремня** — клиновой, поликлиновой, зубчатый
2. **Профиль** — сечение (ширина × высота)
3. **Длина** — внутренняя или эффективная

### Измерение клинового ремня

| Параметр | Обозначение | Как измерить |
|----------|-------------|--------------|
| Ширина верха | Wp | Линейкой по верхней грани |
| Высота | H | Штангенциркулем |
| Внутренняя длина | Li | Рулеткой по внутренней поверхности |
| Расчётная длина | Lp | Li + Δ (зависит от профиля) |

### Пересчёт длин

| Профиль | Δ = Lp - Li |
|---------|-------------|
| Z | +31 мм |
| A | +33 мм |
| B | +43 мм |
| C | +56 мм |

### Определение профиля клинового

| Ширина, мм | Высота, мм | Профиль |
|------------|------------|---------|
| 10 ± 0.5 | 6 ± 0.3 | Z (О) |
| 13 ± 0.5 | 8 ± 0.4 | A (А) |
| 17 ± 0.5 | 11 ± 0.5 | B (Б) |
| 22 ± 0.5 | 14 ± 0.5 | C (В) |

### Измерение поликлинового

1. Посчитать количество ручьёв
2. Измерить общую ширину
3. Определить профиль (PJ, PK, PL, PM)
4. Измерить длину

### Измерение зубчатого

1. Посчитать количество зубьев
2. Измерить шаг (расстояние между зубьями)
3. Измерить ширину

## Алгоритм подбора

```
1. Определить тип ремня
2. Измерить сечение → профиль
3. Измерить длину
4. Найти по каталогу ближайший размер
5. Проверить совместимость со шкивами
```

## Частые ошибки

- Путают внутреннюю (Li) и расчётную (Lp) длину
- Неправильно определяют профиль
- Ставят ремень неподходящей ширины
