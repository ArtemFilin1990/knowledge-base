# Неисправности ременной передачи

Диагностика и устранение типичных неисправностей ременных передач.

## Контекст применения

- Диагностика причин выхода ремня из строя
- Профилактика преждевременного износа
- Правильная эксплуатация

## Ключевые пункты

### Типичные неисправности

| Неисправность | Признаки | Причины |
|---------------|----------|---------|
| Износ боковых граней | Истирание, уменьшение ширины | Проскальзывание, малое натяжение |
| Трещины на спинке | Поперечные трещины | Перегиб на малом шкиве |
| Расслоение | Отслоение корда | Перегрев, химическое воздействие |
| Обрыв | Полный разрыв | Перегрузка, старение |
| Соскакивание | Сход со шкива | Несоосность, износ шкивов |
| Писк/свист | Шум при работе | Проскальзывание |

### Причины преждевременного износа

1. **Неправильное натяжение**
   - Слабое → проскальзывание → нагрев → износ
   - Избыточное → перегрузка подшипников

2. **Несоосность шкивов**
   - Угловая → неравномерный износ
   - Параллельная → боковой износ

3. **Перегрев**
   - Высокая температура окружающей среды
   - Проскальзывание
   - Близость горячих поверхностей

4. **Загрязнение**
   - Масло, топливо → разрушение резины
   - Пыль → абразивный износ

### Как проверить натяжение

**Метод прогиба:**
- Приложить усилие посередине ветви
- Прогиб должен быть 1,5–2% длины ветви
- Или 15–20 мм на 1 м длины

**Метод частоты вибрации:**
- Используется специальный прибор
- Точный метод для ответственных передач

### Проверка соосности

- Линейка вдоль боковых граней шкивов
- Лазерный инструмент для точных применений
- Допуск: 0,5° угловая, 0,5 мм/100 мм параллельная

## Алгоритм диагностики

1. Визуальный осмотр ремня
2. Проверка натяжения
3. Проверка соосности шкивов
4. Осмотр шкивов на износ
5. Проверка подшипников
6. Анализ условий работы
