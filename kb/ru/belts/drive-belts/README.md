# Приводные ремни

Обзор типов приводных ремней и их применения.

## Контекст применения

- Выбор типа ремня для привода
- Понимание различий между типами
- Замена и обслуживание ременных передач

## Ключевые пункты

### Типы приводных ремней

| Тип | Профиль | Применение |
|-----|---------|------------|
| Клиновой (V-belt) | Трапеция | Промышленность, авто |
| Узкий клиновой | SPZ, SPA, SPB | Современная промышленность |
| Поликлиновой | PJ, PK, PL, PM | Автомобили, бытовая техника |
| Зубчатый (HTD, GT) | Зубья | Синхронные передачи |
| Плоский | Прямоугольник | Конвейеры |

### Клиновые ремни — профили

| Профиль | Ширина верха, мм | Высота, мм |
|---------|------------------|------------|
| Z (10) | 10 | 6 |
| A (13) | 13 | 8 |
| B (17) | 17 | 11 |
| C (22) | 22 | 14 |
| D (32) | 32 | 19 |

### Узкие клиновые (Narrow V)

| Профиль | Ширина, мм | Высота, мм |
|---------|------------|------------|
| SPZ | 9.7 | 8 |
| SPA | 12.7 | 10 |
| SPB | 16.3 | 13 |
| SPC | 22 | 18 |

### Поликлиновые ремни

| Профиль | Шаг, мм | Глубина ручья, мм |
|---------|---------|------------------|
| PJ | 2.34 | 0.4 |
| PK | 3.56 | 0.9 |
| PL | 4.7 | 2.4 |
| PM | 9.4 | 3.5 |

### Зубчатые ремни

| Профиль | Шаг, мм | Применение |
|---------|---------|------------|
| MXL | 2.032 | Миниатюрные |
| XL | 5.08 | Лёгкие |
| L | 9.525 | Средние |
| H | 12.7 | Тяжёлые |
| HTD 3M | 3 | Современные |
| HTD 5M | 5 | Современные |
| HTD 8M | 8 | Мощные |

## Маркировка

### Клиновые ремни

```
A-1000 или A/1000
```
- A — профиль
- 1000 — внутренняя длина Li, мм

### Поликлиновые

```
5PK1200
```
- 5 — количество ручьёв
- PK — профиль
- 1200 — эффективная длина, мм
