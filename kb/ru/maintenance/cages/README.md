# Сепараторы подшипников качения

Типы сепараторов, материалы и их влияние на характеристики подшипника.

## Контекст применения

- Выбор подшипника по типу сепаратора
- Понимание ограничений по скорости и температуре
- Расшифровка обозначений

## Ключевые пункты

### Функции сепаратора

- Разделение тел качения
- Равномерное распределение по окружности
- Удержание тел качения при монтаже
- Участие в смазке (направление потока)

### Материалы сепараторов

| Материал | Обозначение | Характеристики |
|----------|-------------|----------------|
| Сталь штампованная | J, — | Дёшево, до +120°C |
| Латунь массивная | M, MA | До +200°C, высокие скорости |
| Полиамид (PA66) | TN, P | Лёгкий, до +120°C |
| Стеклонаполненный PA | TNH, TNG | До +140°C |
| Текстолит | E | До +100°C |
| PEEK | — | До +250°C, химстойкость |
| Фенолопласт | F | До +100°C |

### Типы конструкции

| Тип | Описание | Применение |
|-----|----------|------------|
| Штампованный | Из листового металла | Массовое производство |
| Массивный | Механическая обработка | Высокие скорости |
| Пластиковый | Литьё под давлением | Тихоходные, лёгкие |
| Оконного типа | С окнами под шарики | Высокоскоростные |

### Обозначения в маркировке

| Суффикс | Значение |
|---------|----------|
| J | Штампованный стальной |
| M, MA | Массивный латунный |
| TN | Полиамидный |
| Y | Массивный латунный (SKF) |
| P | Пластиковый |
| E | Текстолитовый |

### Влияние на характеристики

| Параметр | Стальной | Латунный | Пластиковый |
|----------|----------|----------|-------------|
| Макс. скорость | Средняя | Высокая | Средняя |
| Макс. температура | +120°C | +200°C | +120°C |
| Шум | Средний | Низкий | Низкий |
| Стоимость | Низкая | Высокая | Средняя |

## Примеры

- **6205** — штампованный стальной (стандарт)
- **6205 M** — массивный латунный
- **6205 TN** — полиамидный
- **7210 BECBM** — шариковый сепаратор латунный

## Частые ошибки

- Превышение температурного лимита пластика
- Несовместимость сепаратора с агрессивной средой
- Игнорирование требований к скорости
