# Хранение и упаковка подшипников

Правила хранения подшипников для сохранения их работоспособности.

## Контекст применения

- Организация складского хранения
- Приёмка подшипников
- Подготовка к длительному хранению

## Ключевые пункты

### Условия хранения

| Параметр | Требование |
|----------|------------|
| Температура | +10...+30°C (оптимально +20°C) |
| Влажность | До 60% |
| Освещение | Без прямых солнечных лучей |
| Вибрации | Отсутствие |
| Загрязнения | Чистое, сухое помещение |

### Сроки хранения

| Условия | Срок хранения |
|---------|---------------|
| Заводская упаковка, оптимальные условия | 3–5 лет |
| Вскрытая упаковка | До 1 года |
| Неблагоприятные условия | До 6 месяцев |

### Правила хранения

1. **Хранить в заводской упаковке** до момента установки
2. **Горизонтальное положение** для радиальных подшипников
3. **Не складывать тяжёлые на лёгкие**
4. **Крупные подшипники** — на деревянных поддонах
5. **Периодический осмотр** — раз в 6 месяцев

### Признаки неправильного хранения

- Коррозия на поверхностях
- Высохшая или загустевшая смазка
- Повреждённая упаковка
- Следы влаги внутри упаковки

## Алгоритм приёмки

1. Проверить целостность упаковки
2. Сверить маркировку с накладной
3. Визуально осмотреть подшипник
4. Проверить лёгкость вращения
5. Зафиксировать дату приёмки

## Частые ошибки

- Хранение в сырых помещениях
- Вскрытие упаковки заранее
- Хранение вблизи химикатов
- Укладка друг на друга без прокладок
