# Монтаж подшипников

Правила и методы установки подшипников на вал и в корпус.

## Контекст применения

- Первичный монтаж подшипников
- Замена изношенных подшипников
- Сборка подшипниковых узлов

## Ключевые пункты

### Основные правила монтажа

1. **Чистота** — рабочее место, инструмент и детали должны быть чистыми
2. **Усилие через кольцо** — усилие напрессовки только через монтируемое кольцо
3. **Не через тела качения** — никогда не передавать усилие через шарики/ролики
4. **Правильный инструмент** — монтажные втулки, съёмники, индукционные нагреватели

### Методы монтажа

| Метод | Применение | Преимущества |
|-------|------------|--------------|
| Холодная напрессовка | Малые подшипники, лёгкий натяг | Простота |
| Нагрев подшипника | Средние и крупные подшипники | Не повреждает подшипник |
| Охлаждение вала | Крупные валы | Без нагрева подшипника |
| Гидравлический метод | Конические посадки | Точный контроль |
| Масляная инжекция | Подшипники с отверстиями | Лёгкий демонтаж |

### Нагрев подшипника

- **Температура:** 80–100°C (не выше 120°C!)
- **Способы:** индукционный нагреватель, масляная ванна, печь
- **Время:** зависит от размера, обычно 15–30 минут
- **Контроль:** термокарандаш или пирометр

### Монтажное усилие

| Посадка | Усилие напрессовки |
|---------|-------------------|
| j5, j6 | Лёгкое, от руки |
| k5, k6 | Среднее, молоток через втулку |
| m5, m6 | Значительное, пресс |
| n6, p6 | Большое, нагрев или пресс |

## Алгоритм монтажа

1. Проверить соответствие подшипника чертежу
2. Проверить размеры вала и корпуса
3. Очистить посадочные поверхности
4. Нанести тонкий слой масла
5. Нагреть подшипник (при необходимости)
6. Напрессовать до упора
7. Зафиксировать (гайка, кольцо)
8. Проверить лёгкость вращения

## Частые ошибки

- Удары по наружному кольцу при монтаже на вал
- Перегрев подшипника (выше 120°C)
- Монтаж без смазки посадочных поверхностей
- Перекос при напрессовке
- Использование неподходящего инструмента
