# Переконсервация подшипников

Замена консервационной смазки на рабочую перед монтажом.

## Контекст применения

- Подготовка новых подшипников к установке
- Замена смазки после длительного хранения
- Переход на специальную смазку

## Ключевые пункты

### Когда нужна переконсервация

- Консервационная смазка не соответствует рабочей
- Подшипник хранился более 2 лет
- Требуется специальная смазка (пищевая, высокотемпературная)
- Видны следы загустевания или высыхания

### Когда переконсервация НЕ нужна

- Подшипники с постоянной смазкой (2RS, ZZ)
- Смазка соответствует рабочим условиям
- Подшипник из свежей партии

### Промывочные жидкости

| Жидкость | Применение | Примечания |
|----------|------------|------------|
| Бензин (нефрас) | Общее применение | Огнеопасен |
| Уайт-спирит | Общее применение | Менее летучий |
| Керосин | Крупные подшипники | Дёшево |
| Специальные очистители | Прецизионные | Дорого |

### Процесс переконсервации

1. **Подготовка** — чистая тара, промывочная жидкость, смазка
2. **Первая промывка** — удаление основной массы консерванта
3. **Вторая промывка** — в чистой жидкости
4. **Сушка** — сжатым воздухом или естественная
5. **Смазывание** — нанесение рабочей смазки
6. **Упаковка** — если не монтируется сразу

## Алгоритм

```
1. Погрузить в промывочную ванну
2. Вращать кольца 1–2 минуты
3. Переложить в чистую жидкость
4. Повторить вращение
5. Извлечь, дать стечь
6. Продуть сжатым воздухом (БЕЗ вращения!)
7. Сразу нанести рабочую смазку
8. Установить или упаковать
```

## Частые ошибки

- Вращение подшипника сжатым воздухом (разгон без смазки!)
- Использование воды для промывки
- Оставление подшипника без смазки после промывки
- Недостаточная сушка перед смазыванием
