# Ревизия подшипников

Методы диагностики состояния подшипников и оценка их пригодности.

## Контекст применения

- Плановое техническое обслуживание
- Диагностика при появлении шума/вибрации
- Оценка состояния перед повторным использованием

## Ключевые пункты

### Методы диагностики

| Метод | Что выявляет | Оборудование |
|-------|--------------|--------------|
| Визуальный осмотр | Коррозия, износ, сколы | Лупа, освещение |
| Проверка на слух | Шум, стук | — |
| Измерение зазоров | Износ, ослабление | Индикатор |
| Вибродиагностика | Дефекты дорожек, тел качения | Виброанализатор |
| Температурный контроль | Перегрев | Пирометр |

### Визуальный осмотр

Что проверять:
- Дорожки качения — питтинг, выкрашивание, риски
- Тела качения — сколы, плоские участки
- Сепаратор — трещины, износ
- Уплотнения — повреждения, высыхание
- Следы коррозии или перегрева

### Признаки неисправности

| Признак | Возможная причина |
|---------|-------------------|
| Повышенный шум | Износ, загрязнение |
| Вибрация | Дефект дорожки, тел качения |
| Нагрев | Недостаток смазки, перегрузка |
| Увеличенный зазор | Износ |
| Заедание | Загрязнение, разрушение сепаратора |

### Критерии замены

Подшипник подлежит замене при:
- Питтинге на дорожках качения
- Сколах на телах качения
- Трещинах сепаратора
- Следах перегрева (цвета побежалости)
- Увеличении зазора выше допустимого

## Алгоритм ревизии

1. Очистить подшипник (бензин, керосин)
2. Высушить сжатым воздухом
3. Визуально осмотреть все поверхности
4. Проверить лёгкость вращения
5. Измерить радиальный зазор
6. Принять решение: годен/ремонт/замена

## Частые ошибки

- Использование агрессивных растворителей
- Вращение без смазки после промывки
- Игнорирование начальных признаков износа
- Повторное использование изношенных подшипников
