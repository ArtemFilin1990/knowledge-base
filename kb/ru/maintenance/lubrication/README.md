# Смазка подшипников

Выбор и применение смазочных материалов для подшипников качения.

## Контекст применения

- Выбор типа смазки для конкретного применения
- Определение количества и интервалов смазки
- Замена смазки при обслуживании

## Ключевые пункты

### Типы смазки

| Тип | Применение | Температурный диапазон |
|-----|------------|------------------------|
| Пластичная смазка | 90% применений | -30...+120°C |
| Жидкое масло | Высокие скорости, циркуляция | -20...+100°C |
| Твёрдые смазки | Экстремальные температуры | -200...+400°C |

### Пластичные смазки по загустителю

| Загуститель | Характеристики | Применение |
|-------------|----------------|------------|
| Литиевый | Универсальный, водостойкий | Общее применение |
| Литий-комплекс | Высокие температуры | Подшипники ступиц |
| Полимочевина | Длительный срок службы | Электродвигатели |
| Кальциевый | Водостойкость | Влажная среда |
| Натриевый | Высокие температуры | Горячие узлы |

### Количество смазки

**Правило:** Заполнение свободного пространства на 30–50%.

- **Недостаток** → износ, сухое трение
- **Избыток** → перегрев, выдавливание уплотнений

### Формула объёма смазки (ориентировочно)

```
V = 0.005 × D × B (см³)
```

где D — наружный диаметр (мм), B — ширина (мм)

### Интервалы смазывания

Зависят от:
- Частоты вращения
- Температуры
- Нагрузки
- Условий среды

**Ориентир:** От 1 раза в год (закрытые) до ежедневно (тяжёлые условия).

## Примеры выбора

| Применение | Рекомендуемая смазка |
|------------|---------------------|
| Электродвигатель | Полимочевина, NLGI 2–3 |
| Автомобильная ступица | Литий-комплекс, EP-добавки |
| Конвейер | Литиевая, NLGI 2 |
| Пищевое оборудование | Пищевая смазка H1 |
| Высокие температуры | Синтетика, фторуглеродная |

## Частые ошибки

- Смешивание несовместимых смазок
- Переполнение подшипника смазкой
- Использование неподходящей смазки для температуры
- Смазка закрытых подшипников (2RS, ZZ)
