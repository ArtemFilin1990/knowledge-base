# Посадки подшипников

Рекомендации по выбору посадок внутреннего кольца на вал и наружного кольца в корпус.

## Контекст применения

- Проектирование подшипниковых узлов
- Выбор допусков вала и корпуса
- Обеспечение правильной работы подшипника

## Ключевые пункты

### Принцип выбора посадки

**Вращающееся кольцо** должно иметь посадку с **натягом**.
**Неподвижное кольцо** может иметь посадку с **зазором**.

### Посадки внутреннего кольца на вал

| Условия работы | Поле допуска вала | Тип посадки |
|----------------|-------------------|-------------|
| Лёгкие нагрузки, неопределённое направление | g6, h6 | С зазором |
| Нормальные нагрузки, вращающийся вал | k6, m6 | Переходная |
| Тяжёлые нагрузки, удары | n6, p6 | С натягом |
| Особо тяжёлые нагрузки | r6, s6 | Сильный натяг |

### Посадки наружного кольца в корпус

| Условия работы | Поле допуска корпуса | Тип посадки |
|----------------|---------------------|-------------|
| Вращающийся корпус | N7, P7 | С натягом |
| Осевое перемещение желательно | G7, H7 | С зазором |
| Неопределённое направление нагрузки | J7, K7 | Переходная |
| Тяжёлые ударные нагрузки | M7, N7 | С натягом |

### Стандартные сочетания

| Применение | Вал | Корпус |
|------------|-----|--------|
| Электродвигатели, лёгкие | j6, k6 | H7 |
| Редукторы, средние | k6, m6 | H7, J7 |
| Прокатные станы | n6, p6 | M7, N7 |
| Ступицы колёс | k6, m6 | J7, K7 |

## Примеры

### Пример 1: Электродвигатель
- Вал вращается → внутреннее кольцо с натягом
- Корпус неподвижен → наружное кольцо с зазором
- **Рекомендация:** вал k6, корпус H7

### Пример 2: Ступица колеса
- Корпус (ступица) вращается → наружное кольцо с натягом
- Ось неподвижна → внутреннее кольцо с зазором
- **Рекомендация:** вал g6, корпус N7

## Частые ошибки

- Посадка обоих колец с натягом → защемление тел качения
- Посадка обоих колец с зазором → проворот колец
- Слишком сильный натяг → уменьшение зазора, перегрев

## Алгоритм выбора

1. Определить, какое кольцо вращается
2. Оценить величину и характер нагрузки
3. Выбрать базовую посадку из таблиц
4. Проверить влияние на внутренний зазор
5. При необходимости скорректировать зазор подшипника
