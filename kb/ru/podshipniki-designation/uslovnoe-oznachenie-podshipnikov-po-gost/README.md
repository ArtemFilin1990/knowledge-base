# Условное обозначение подшипников по ГОСТ

## Назначение стандарта

Условное обозначение подшипников качения по ГОСТ 3485-78 и смежным стандартам определяет единую систему кодирования типа, размера, класса точности, зазора и конструктивных особенностей подшипника.

Цель — обеспечить однозначное понимание характеристик изделия при заказе, подборе аналога и обмене данными между производителями, поставщиками и потребителями.

**Основные стандарты:**
- ГОСТ 3485-78 — Подшипники качения. Общие технические условия
- ГОСТ 520-2011 — Подшипники качения. Общие технические условия (актуализированная версия)
- ГОСТ 3478-2012 — Подшипники качения. Условные обозначения

## Как читать обозначение

Условное обозначение подшипника состоит из основного обозначения и дополнительных знаков (префиксов и суффиксов).

**Общая структура:**

```
[Префикс] [Основное обозначение] [Суффикс]
```

**Пример:**
`6-180305 АС17 Ш`

Где:
- `6` — префикс (класс точности)
- `180305` — основное обозначение (категория + серия + диаметр)
- `АС17` — суффикс (конструктивное исполнение: радиально-упорный с углом контакта 25°, упорный бортик на наружном кольце)
- `Ш` — суффикс (материал сепаратора — штампованный)

## Структура основного обозначения

Основное обозначение читается **справа налево** и состоит из:

| Позиция (справа) | Кодируется | Количество символов | Пример |
|---|---|---|---|
| 1–2 символа | Внутренний диаметр (d) | 2 цифры | `05` → d = 25 мм |
| 3 символ | Серия диаметров (D) | 1 цифра | `3` → серия диаметров |
| 4 символ | Серия ширины (B/H) | 1 цифра | `0` → серия ширины |
| 5–7 символы | Категория (тип) подшипника | 1–3 цифры или буквы | `18` → конический роликовый |

**Пример расшифровки:** `180305`
- `05` → d = 25 мм
- `3` → серия диаметров (средняя)
- `0` → серия ширины (нормальная)
- `18` → категория (конический роликовый подшипник)

## Префиксы: класс точности и зазор

**Класс точности** ставится перед основным обозначением через дефис.

| Класс точности | Обозначение | Применение |
|---|---|---|
| Нормальный | 0 (не указывается) | Общепромышленные применения |
| Повышенный | 6 | Средние нагрузки, средние скорости |
| Высокий | 5 | Станки, электродвигатели |
| Прецизионный | 4, 2, Т | Шпиндели, метрология |

**Пример:** `6-305` — подшипник шариковый радиальный однорядный, класс точности 6, d = 25 мм.

**Зазор** обозначается после класса точности:

| Зазор | Обозначение | Применение |
|---|---|---|
| Меньше нормального | С1 | Точные нагруженные узлы |
| Нормальный | С0 (не указывается) | Общепромышленное |
| Больше нормального | С3, С4, С5 | Высокая температура, посадка с натягом |

**Пример:** `6С3-305` — подшипник класс точности 6, зазор С3, d = 25 мм.

## Суффиксы: конструкция и материалы

Суффиксы указываются **после** основного обозначения через пробел или без него.

| Суффикс | Что означает |
|---|---|
| Н | Один защитный щиток с одной стороны |
| 2Н | Два защитных щитка |
| Р | Одно уплотнение (резиновое) |
| 2Р | Два уплотнения |
| Ш | Сепаратор штампованный |
| Л | Сепаратор латунный |
| ЛУ | Латунь усиленная |
| Г | Сепаратор из графита |
| АС17 | Радиально-упорный, угол контакта 25° |
| Е | Специальная геометрия (усиленная конструкция) |

**Пример:** `305 2Р` — подшипник с двумя резиновыми уплотнениями.

## Частые ошибки

| Ошибка | Почему нельзя | Как правильно |
|---|---|---|
| Сравнивать обозначения без учёта суффиксов | Подшипники 305 и 305 2Р имеют разные уплотнения и ресурс | Учитывать полное обозначение |
| Заменять подшипник только по диаметру | Категория, серия и зазор влияют на нагрузку и срок службы | Проверять полную геометрию и исполнение |
| Игнорировать знак года выпуска | Невозможно определить актуальность консервации | См. таблицу знака года выпуска |
| Подбирать аналог без проверки класса точности | Точность влияет на шумность, ресурс и стабильность | Сверять класс точности (ГОСТ ↔ ISO ↔ ABEC) |
