# Обозначение момента трения

Классы подшипников по моменту трения и их обозначение в условном обозначении по ГОСТ.

## Контекст применения

- Выбор подшипников для прецизионных приборов
- Подбор подшипников для высокоскоростных применений
- Заказ подшипников с нормированным моментом трения

## Ключевые пункты

Класс момента трения указывается **перед основным обозначением** через дефис.

### Классы момента трения

| Класс | Характеристика | Применение |
|-------|----------------|------------|
| 1 | Лёгкий пуск | Приборы, электродвигатели малой мощности |
| 2 | Пониженный момент | Гироскопы, точные приборы |
| 3 | Особо низкий момент | Прецизионные приборы |
| 4 | Минимальный момент | Высокоточные гироскопы |
| 5 | Стабильный момент | Специальные применения |

### Структура обозначения

```
[Класс момента]-[Класс точности]-[Основное обозначение]
```

Пример: **2-6-205** — класс момента 2, класс точности 6, подшипник 205

## Примеры

- **1-5-1000904** → класс момента 1, класс точности 5
- **2-4-46205** → класс момента 2, класс точности 4, радиально-упорный
- **3-2-8100** → класс момента 3, класс точности 2, упорный

## Частые ошибки

- Путают класс момента трения с классом точности
- Не все подшипники выпускаются во всех классах момента
