# Обозначение внутреннего диаметра

Правила кодирования внутреннего диаметра (d) подшипника в условном обозначении по ГОСТ.

## Контекст применения

- Определение диаметра вала по обозначению подшипника
- Правильное формирование обозначения при заказе
- Подбор подшипника по размеру вала

## Ключевые пункты

Внутренний диаметр кодируется **двумя последними цифрами** основного обозначения.

### Диаметры от 20 до 495 мм

Две последние цифры умножаются на 5:
- **04** → d = 20 мм
- **05** → d = 25 мм
- **10** → d = 50 мм
- **20** → d = 100 мм
- **99** → d = 495 мм

### Диаметры от 10 до 17 мм (исключения)

| Код | Диаметр d, мм |
|-----|---------------|
| 00 | 10 |
| 01 | 12 |
| 02 | 15 |
| 03 | 17 |

### Диаметры менее 10 мм

Указывается непосредственно размер:
- **6** → d = 6 мм
- **8** → d = 8 мм
- **9** → d = 9 мм

### Диаметры 500 мм и более

Указывается через косую черту: `/500`, `/530` и т.д.

## Примеры

- **6205** → код 05 → d = 5 × 5 = 25 мм
- **6302** → код 02 → d = 15 мм (исключение)
- **NU 1020** → код 20 → d = 20 × 5 = 100 мм
- **608** → код 8 → d = 8 мм

## Частые ошибки

- Забывают про исключения для d = 10, 12, 15, 17 мм
- Путают диаметры менее 10 мм с кодами серий
