# Обозначение категорий подшипников

Справочник по кодам категорий (типов) подшипников качения в условном обозначении по ГОСТ.

## Контекст применения

- Расшифровка типа подшипника по его обозначению
- Подбор аналогов по категории
- Составление заказа на подшипники

## Ключевые пункты

Категория подшипника указывается **цифрой перед размерной серией** (4-я позиция справа в основном обозначении).

| Код | Категория подшипника |
|-----|---------------------|
| 0 | Шариковый радиальный (часто опускается) |
| 1 | Шариковый радиальный сферический |
| 2 | Роликовый радиальный с короткими цилиндрическими роликами |
| 3 | Роликовый радиальный сферический |
| 4 | Роликовый радиальный игольчатый или с длинными роликами |
| 5 | Роликовый радиальный с витыми роликами |
| 6 | Шариковый радиально-упорный |
| 7 | Роликовый конический |
| 8 | Шариковый упорный, шариковый упорно-радиальный |
| 9 | Роликовый упорный, роликовый упорно-радиальный |

## Примеры

- **6-205** → 0 (шариковый радиальный), серия 02, d=25 мм
- **3205** → 6 (шариковый радиально-упорный), серия 02, d=25 мм
- **7205** → 7 (роликовый конический), серия 02, d=25 мм
- **2210** → 2 (роликовый с цилиндрическими роликами), серия 22, d=50 мм

## Частые ошибки

- Путают категорию 0 с отсутствием обозначения (0 часто не пишется)
- Путают шариковый радиально-упорный (6) с роликовым коническим (7)
