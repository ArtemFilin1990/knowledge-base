# Обозначение размерных серий

Кодирование серий по ширине и наружному диаметру подшипников в условном обозначении по ГОСТ.

## Контекст применения

- Понимание габаритов подшипника по обозначению
- Выбор между лёгкой, средней и тяжёлой сериями
- Подбор аналогов с учётом размерной серии

## Ключевые пункты

Размерная серия состоит из двух частей:
- **Серия диаметров** (третья цифра справа)
- **Серия ширин** (четвёртая цифра справа, после категории)

### Серии диаметров

| Код | Серия | Характеристика |
|-----|-------|----------------|
| 0 | Сверхлёгкая | Минимальный наружный диаметр |
| 1 | Особо лёгкая | |
| 2 | Лёгкая | Наиболее распространённая |
| 3 | Средняя | |
| 4 | Тяжёлая | Максимальный наружный диаметр |

### Серии ширин

| Код | Серия | Характеристика |
|-----|-------|----------------|
| 0 | Нормальная | Стандартная ширина (часто опускается) |
| 1 | Узкая | |
| 2 | Нормальная | |
| 3 | Широкая | |
| 4 | Особо широкая | |

## Примеры

- **205** → серия диаметров 2 (лёгкая), серия ширин 0 (нормальная)
- **305** → серия диаметров 3 (средняя), серия ширин 0 (нормальная)
- **2205** → серия диаметров 2, серия ширин 2 (двухрядный)
- **NU 310** → серия диаметров 3, серия ширин 1 (узкая)

### Сравнение серий для d = 25 мм

| Обозначение | D, мм | B, мм | Серия |
|-------------|-------|-------|-------|
| 6005 | 47 | 12 | Лёгкая узкая |
| 6205 | 52 | 15 | Лёгкая нормальная |
| 6305 | 62 | 17 | Средняя |
| 6405 | 80 | 21 | Тяжёлая |

## Частые ошибки

- Путают серию диаметров с серией ширин
- Не учитывают, что код 0 часто опускается
