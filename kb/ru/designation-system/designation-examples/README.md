# Примеры условного обозначения

Практические примеры расшифровки условных обозначений подшипников по ГОСТ.

## Контекст применения

- Обучение расшифровке обозначений
- Проверка правильности понимания системы
- Составление корректных заявок на подшипники

## Пример 1: 6-180306С17

**Разбор слева направо:**

| Элемент | Значение |
|---------|----------|
| 6 | Класс точности 6 (нормальный) |
| 1 | Серия ширин 1 (узкая) |
| 8 | Категория — упорный шариковый |
| 03 | Серия диаметров 0, серия ширин 3 |
| 06 | Внутренний диаметр: 06 × 5 = 30 мм |
| С17 | Дополнительное обозначение (смазка) |

**Итог:** Упорный шариковый подшипник, d=30 мм, класс точности 6, со смазкой.

## Пример 2: 4-32310А

**Разбор:**

| Элемент | Значение |
|---------|----------|
| 4 | Класс точности 4 (высокий) |
| 3 | Серия ширин 3 (широкая) |
| 2 | Серия диаметров 2 (лёгкая) |
| 3 | Категория — роликовый сферический |
| 10 | Внутренний диаметр: 10 × 5 = 50 мм |
| А | Конструктивная разновидность |

**Итог:** Роликовый сферический двухрядный, d=50 мм, класс точности 4.

## Пример 3: 6-205К

**Разбор:**

| Элемент | Значение |
|---------|----------|
| 6 | Класс точности 6 |
| 2 | Серия диаметров 2 (лёгкая) |
| 0 | Серия ширин 0, категория 0 (шариковый радиальный) |
| 05 | Внутренний диаметр: 05 × 5 = 25 мм |
| К | Конструктивное исполнение (коническое отверстие) |

**Итог:** Шариковый радиальный, d=25 мм, с коническим отверстием.

## Пример 4: 7208А

**Разбор:**

| Элемент | Значение |
|---------|----------|
| 7 | Категория — роликовый конический |
| 2 | Серия диаметров 2 |
| 0 | Серия ширин 0 |
| 08 | Внутренний диаметр: 08 × 5 = 40 мм |
| А | Увеличенный угол контакта |

**Итог:** Роликовый конический однорядный, d=40 мм, с увеличенным углом.

## Пример 5: 2-6-46206Е

**Разбор:**

| Элемент | Значение |
|---------|----------|
| 2 | Класс момента трения 2 |
| 6 | Класс точности 6 |
| 4 | Серия ширин 4 |
| 6 | Категория — шариковый радиально-упорный |
| 2 | Серия диаметров 2 |
| 06 | Внутренний диаметр: 30 мм |
| Е | Сепаратор из текстолита |

**Итог:** Шариковый радиально-упорный, d=30 мм, класс точности 6, класс момента 2.

## Алгоритм расшифровки

1. Определить наличие префиксов (класс момента, класс точности)
2. Выделить основное обозначение (цифры до суффикса)
3. Последние 2 цифры → внутренний диаметр
4. 3-я справа → серия диаметров
5. 4-я справа → категория + серия ширин
6. Суффиксы → конструктивные особенности
