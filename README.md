# Knowledge Base

Централизованная база знаний с контролируемым циклом: **загрузка → классификация → публикация → индекс**.

## Быстрый старт

1. Загрузите материалы в [`inbox/`](./inbox/).
2. Запустите обработчик:
   ```bash
   python scripts/process_inbox.py
   ```
   Либо просто сделайте push в `main` — обработка выполняется GitHub Actions.
3. Проверьте результат в [`kb/ru/`](./kb/ru/) и центральном индексе: [`kb/ru/INDEX.md`](./kb/ru/INDEX.md).

Подробности: [`docs/inbox-processor.md`](./docs/inbox-processor.md).

## Назначение

- Хранить проверенные статьи как **source of truth**.
- Изолировать «сырьё» (`inbox/`) от каноничного контента (`kb/ru/`).
- Обеспечить навигацию и масштабирование через индексы.

## Структура репозитория

- `inbox/` — единственная точка входа для новых материалов (сырые файлы пользователя).
- `inbox/processed/` — автоматически обработанные исходники.
- `kb/ru/` — каноничная база знаний на русском языке (готовые статьи).
- `kb/ru/INDEX.md` — центральный индекс всех статей.
- `_templates/` — шаблоны оформления статей.
- `docs/` — документация по процессам и регламентам.
- `scripts/` — автоматизация (обработка inbox, генераторы, quality gate).
- `tests/` — проверки (ссылки, валидаторы, sanity checks).
- `_meta/` — метаданные (темы, дедупликация, аудит).
- `prompts/` — рабочие промпты для агента.

## Правила добавления контента

1. Новые материалы добавляются **только** через `inbox/`.
2. Каноничный контент живёт **только** в `kb/ru/`.
3. Одна статья = одна папка = один файл `README.md`.
4. Имена папок — `kebab-case` (ASCII), без пробелов и кириллицы.
5. Каждая статья содержит front-matter и стандартные блоки (см. шаблон).
6. Индексы обновляются автоматически — вручную редактировать их не нужно.

Шаблон статьи: [`_templates/article.md`](./_templates/article.md).
Аудит и рекомендации: [`_meta/repository-audit.md`](./_meta/repository-audit.md).

## Скрипты и автоматизация

- **Обработка inbox**: `python scripts/process_inbox.py`
- **Генерация карточек подшипников**: `python scripts/generate_bearing_cards.py`
- **Проверка качества (quality gate)**: `python scripts/kb_quality_gate.py`
- **Валидация карточек**: `python scripts/validate_bearing_cards.py`
- **Проверка ссылок**: `python tests/check_kb_links.py`

## Проверки

- Ссылки в базе знаний: `python tests/check_kb_links.py`
- Метаданные и структура: `python scripts/kb_quality_gate.py`
