## Слой 3. Рекомендации по сборке в Bitrix24
- Меню: древовидное (уровень 1 и 2 — разделы, уровень 3 — конечные страницы).
- Шаблоны страниц: настроить семь шаблонов (A-G) и связать с `page_type` (guide, table, hub, brand-page, service, article, reference, glossary, media).
- Таблицы: для `page_type = table` использовать стандартный компонент «Таблица» или HTML-таблицы без изображений.
- Перелинковка: в блоках «См. также» ставить ссылки на родственные страницы по их `slug` (например, `zazory-v-podshipnikah-kacheniya` -> `klass-tochnosti-gost-iso-abec`).
- Статусы: начинать со `planned`, после написания ставить `draft`, после внутреннего ревью — `ready`.
- Внешний вид: светлая тема, чёрные заголовки H1–H3, акцентный цвет только для ссылок.
